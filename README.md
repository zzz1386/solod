# От солода к стилю

Сайт курса о пиве для российской аудитории: история, сорта, стили и дегустация.

Каркас готов. Полные тексты уроков можно добавлять в страницы `src/app/lessons/[slug]` и в данные `src/data/course.ts`, не ломая навигацию.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

Сайт на GitHub Pages собирается workflow из статического экспорта, а не из README. В репозитории выберите **Settings → Pages → Source → GitHub Actions**.

## Структура сайта

| Маршрут | Назначение |
| --- | --- |
| `/` | Главная: о курсе и модулях |
| `/program` | Все 24 урока |
| `/modules` | Список модулей |
| `/modules/[slug]` | Уроки одного модуля |
| `/lessons/[slug]` | Страница урока: цель, темы, факт, практика |
| `/how-to` | Как учиться, правила, минимальная полка |
| `/exam` | Тест: 7 вопросов, один ответ из четырёх |
| `/journal` | Дневник дегустаций |

## Данные курса

Единый источник правды — `src/data/course.ts`:

- 7 модулей
- 24 урока
- цель, темы, интересный факт и практика у каждого урока

Новый урок: добавьте объект в нужный модуль. Страница появится сама.

## Стек

Next.js App Router, TypeScript, Tailwind CSS. Контент пока в TypeScript, не в CMS — так проще наполнять курс по одному уроку.
